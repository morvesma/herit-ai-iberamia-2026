# HERIT-AI 2026 website

This is the first draft of the HERIT-AI workshop website.

## Files

- `index.html` — website structure and content
- `style.css` — visual design and responsive layout
- `assets/herit-ai-hero.png` — hero image

## To publish with GitHub Pages

1. Create or open the HERIT-AI GitHub repository.
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Save.

Before publication, replace `YOUR_EMAIL_HERE` with the official workshop email and update dates, committee members, and submission information.


The homepage uses the approved HERIT-AI visual banner as the hero image.
